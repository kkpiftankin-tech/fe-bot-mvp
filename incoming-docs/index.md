# Индекс входящих документов

Сырые материалы, которые ещё не обработаны в структурированные артефакты, лежат в [raw/](raw/). После ingestion на каждый файл ссылается `docs/traceability/source-to-artifact-map.md`.

## Workflow

1. Положить исходный файл в [raw/](raw/) с осмысленным именем.
2. Добавить строку в таблицу ниже.
3. Запустить `.claude/skills/ingest-docs/SKILL.md` (или следовать ему вручную), чтобы произвести производные артефакты.
4. По завершении ingestion выставить статус и добавить строки traceability.

## Значения статусов

- `pending` — ещё не открывался.
- `parsed` — контент извлечён, кандидатные факты выявлены.
- `ingested` — производные артефакты созданы и связаны в traceability.
- `archived` — полностью обработан; оригинал сохранён для audit.
