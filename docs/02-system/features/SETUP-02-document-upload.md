# SETUP-02. Загрузка документов

## Назначение

Принять пользовательские исходные документы через UI мастера, провалидировать их и положить в [incoming-docs/raw/](../../../incoming-docs/raw/) плюс реестр источников, чтобы нижестоящие фазы Setup могли их обработать.

## Бизнес-ценность

База знаний хороша ровно настолько, насколько хороши её источники. Загрузка доменных документов через типизированную, валидируемую точку входа — единственный способ сохранить доверие к KB и привязать каждый последующий артефакт к реальному документу, которым владеет пользователь.

## Вход и выход

- **Вход.** Файлы, выбранные в UI (`md`, `txt`, `pdf`, `docx`, `xlsx`, `csv`, `json`), не больше настроенного лимита размера.
- **Выход.** Принятые файлы в Artifact Storage под per-KB префиксом и строки реестра источников ([SETUP-03](SETUP-03-source-registry.md)); для каждого отклонённого файла — причина (неподдерживаемый тип, размер, дубль по checksum).

## Пользовательский сценарий

1. Пользователь перетаскивает файлы в зону загрузки или выбирает их через диалог.
2. UI показывает per-file валидацию: принят / отклонён с причиной (неподдерживаемый тип, слишком большой, дубль по checksum).
3. Принятые файлы сохраняются, регистрируются и видны в [SETUP-03](SETUP-03-source-registry.md).

## Связанные требования

- BR-FR-Setup-021..024 (поддерживаемые типы, max size, дедуп, opt-in).
- NFR-Sec-004 (загрузки opt-in, никогда не автопубликуются).
- Поддерживаемые типы: `.md`, `.txt`, `.pdf`, `.docx`, `.xlsx`, `.csv`, `.json` (список зафиксирован в `SUPPORTED_CONTENT_TYPES`, `schemas/common/defaults.py`; согласован с [SETUP-01 §4.3](SETUP-01-setup-wizard.md)).
- Максимальный размер файла по умолчанию — 100 МБ (`MAX_FILE_SIZE_BYTES`; значение временное, ожидает ADR-006).

## Связанные сервисы

- Frontend Upload Component, Document Upload Service, Validation Service, Artifact Storage, Source Registry Service.

## Связанные контракты

- `UploadedDocument` (`schemas/setup.py`): `file_id`, `original_name`, `mime_type`, `size_bytes`, `checksum_sha256`, `tags`, `uploaded_by`, `uploaded_at`, `status`.

## Критерии приёмки

- Загрузка дубля (тот же checksum) ОБЯЗАНА быть отклонена с кодом `duplicate` и указателем на существующий `file_id`.
- Файлы выше настроенного max size ОБЯЗАНЫ отклоняться до любой записи в storage.
- Принятые файлы ОБЯЗАНЫ попасть в `Artifact Storage` под per-KB префикс и иметь строку в реестре источников.
- Тест: `tests/component/test_setup_document_upload.py`.

## Вне scope

- Streaming / chunked протоколы загрузки (Setup — laptop-scale).
- Антивирусное сканирование (добавляется позже как отдельное middleware).
