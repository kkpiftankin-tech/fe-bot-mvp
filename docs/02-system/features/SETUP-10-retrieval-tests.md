# SETUP-10. Retrieval smoke-тесты

## Назначение

Перед активацией нового индекса прогнать на нём курируемый набор тестовых запросов и проверить, что каждый возвращает ожидаемое семейство документов. Пользователь видит green/red-отчёт; только green разблокирует [SETUP-11](SETUP-11-publish-kb.md).

## Бизнес-ценность

Успешное индексирование не означает работающее retrieval. Неправильно настроенная embedding-модель, опечатка в metadata или регрессия чанкования могут произвести идеально проиндексированную, но бесполезную KB. SETUP-10 — это контракт, говорящий: «я задал эти вопросы, получил эти документы, и это совпадает с тем, что я ожидал».

## Пользовательский сценарий

1. Мастер переходит в фазу **Retrieval tests**.
2. Система грузит eval-сьют из `tests/rag_eval/` и прогоняет каждый запрос на новой `index_version`.
3. Per-запрос пользователь видит: текст запроса, ожидаемый сет `doc_id`, полученный сет `doc_id`, recall@k, precision@k, статус.
4. Сбои показывают, какие ожидаемые docs пропущены и какие top-K docs неожиданны.
5. Пользователь может перезапустить после правки карточек, регенерации или переиндексации — или переопределить с письменным обоснованием (логируется).

## Связанные требования

- BR-FR-Setup-101..104 (eval-сьют, порог recall@k, путь переопределения, форма отчёта).
- Дефолтные пороги: `recall@5 ≥ 0.8` per семейство, отсутствуют запросы с `precision@5 < 0.5`.

## Связанные сервисы

- RAG Evaluation Service, RAG Retrieval Service, Vector DB, Frontend Evaluation Report UI, Test Dataset Registry, API Backend.

## Связанные контракты

- `RetrievalEvalReport` (`schemas/setup.py`): строки per-запрос + общий pass/fail.

## Связанные RAG-документы

- Eval-сьют (запросы + ожидаемые `doc_ids`) лежит под [`tests/rag_eval/`](../../../tests/rag_eval/) — тот же, что использует CI.

## Критерии приёмки

- Падающий отчёт ОБЯЗАН блокировать [SETUP-11](SETUP-11-publish-kb.md).
- Повторный прогон того же eval против неизменённого индекса ОБЯЗАН быть детерминированным.
- Тест: `tests/rag_eval/test_setup_retrieval_smoke.py`.
