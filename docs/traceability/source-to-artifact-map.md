# Source → Artifact (карта)

Эта таблица связывает сырые входы в `incoming-docs/` с произведёнными из них артефактами. У каждого произведённого doc, schema или RAG-карточки должна быть строка.

## Схема

| Source file | Artifact path | Artifact type | Owner | Notes |
| --- | --- | --- | --- | --- |

## Правила

- Добавлять строку в том же изменении, что вводит артефакт.
- Использовать пути относительно репозитория.
- Если вклад внесли несколько источников — перечислить через запятую.
- Произведённый артефакт без источника обязан в колонке source иметь `(internal)` и обоснование в `Notes`.
